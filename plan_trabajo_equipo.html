Agente de Automatización SIA Observa

Este documento detalla la planificación estratégica, arquitectura, diagrama de componentes y secuencia para el despliegue del agente de automatización desarrollado para la Gobernación del Cauca. Diseñado como un software modular y libre de licenciamiento comercial (licencias MIT y Apache 2.0), el agente integra colas BullMQ, workers Playwright y modelos de lenguaje de OpenAI (GPT-4o) para realizar de forma autónoma el procedimiento de descarga, validación, compresión, carga de evidencias contractuales y generación de certificados SIA Observa.

4. Casos de Uso del Agente de Automatización

CU-01: Recepción e Inicio de Solicitud Híbrido

El contratista solicita su certificado enviando un correo al buzón sia.educacion@cauca.gov.co. El Agente detecta el correo de forma periódica (sondeo cada 5m), extrae los datos del mensaje mediante IA (confianza mínima de 50%) y crea un registro de la solicitud en la base de datos de auditoría local en estado pendiente_aprobacion. Envía una notificación WebSockets al Dashboard del supervisor. El supervisor valida los datos y aprueba el inicio del trámite.

CU-02: Descarga de SECOP II, Compresión y Carga en SIA Observa Automático

Una vez aprobada la solicitud, el worker Playwright de SECOP II inicia sesión de forma virtual, busca el contrato y descarga los 4 documentos en formato PDF. El validador comprime mediante Ghostscript aquellos archivos que superen los 4.0 MB. El worker Playwright de SIA Observa inicia sesión, busca el contrato en "Buscar - Contratos", ingresa a "Documentos de Legalidad Anexados", asocia los archivos a la etapa contractual y fase de ejecución, y hace clic en "Insertar anexo", tomando capturas de pantalla de la confirmación como evidencia de auditoría.

CU-03: Generación del Certificado y Envío a Firma Híbrido (Crítico)

El worker de extracción lee el PDF de contrato descargado, clasifica si es Persona Natural o Jurídica, y extrae los datos requeridos. El worker de certificados genera el archivo Word (.docx) a partir de la plantilla y guarda el registro en el archivo de control en Excel. El supervisor valida el Word generado desde la interfaz. Tras la aprobación final, el bot envía el archivo para firma a siadepartamento@cauca.gov.co. Al retornar el certificado firmado en PDF, el bot lo envía automáticamente al contratista.

6. Instrucciones para la Integración con Oracle Database

Para integrar el agente a los servidores de base de datos **Oracle** corporativos de la Gobernación del Cauca:

  1. Instalar el driver oficial de Oracle para Node: npm install oracledb.
  2. Editar el archivo src/config/database.js para inicializar la conexión con el servidor Oracle utilizando las variables de entorno de su host, puerto, usuario y esquema.
  3. Crear el esquema relacional en Oracle importando las tablas adaptadas (con tipos de datos VARCHAR2, NUMBER, TIMESTAMP y restricciones correspondientes).
